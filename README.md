# MALL / INSIGHTS · 商城经营分析与增长决策工作台

首页展示模拟经营指标与历史项目成果，七个交互模块共用 2022.10–2024.09 合成经营数据。历史业绩单列展示。五个 Python 方法示例使用独立模拟样本。

## 本地预览与部署

在仓库根目录运行 `python -m http.server 8000`，打开 http://localhost:8000/。GitHub Pages 发布目录为 `main / (root)`。部署保留 `index.html`、`growth.js`、`methods-display.js`、`mall-data.json` 和 `methods/`。

运行 `python generate.py` 可用固定随机种子重新生成 `mall-data.json`。数据包记录字段定义、四季基准、订单级支付与售后事件、首购队列、历史观察数据和未支付访问分层汇总。

## 指标口径

- 整体成单率为支付访问数除以全部访问数，支付访问在模拟中对应一笔订单。GMV 按支付金额汇总。
- 支付订单退款率以全部支付订单为分母，退款成功订单去重。已发货订单退货率按发货队列单独计算。
- 同季累计复购对比采用满 90 日的首购队列。30 日滚动监控与上年同月对比，两期整月成熟且各至少 100 人时，绝对降幅达到 2 个百分点且相对降幅达到 20% 才提示下钻。阈值为演示配置。
- 触点归因提供末次和线性分摊。独立 A/B、RFM、K-means 和商品 ABC 方法样本在页面内标明样本范围。
