# 垂类商城商业化增长｜数据分析作品集

基于历史业务场景、使用模拟明细数据进行的 Python 数据分析与经营决策看板复现。

## 在线使用

通过 GitHub Pages 访问 `index.html`。无需登录、Python 环境或后端服务。

## 数据说明

- 公开页面内的可筛选用户、访问、商品、订单和实验明细均为模拟数据。
- 案例页中独立标注的历史经营成果来自作者的项目经历，不与模拟明细混算。
- 模拟数据仅用于展示分析方法和产品设计，不代表原企业数据库。
- 本仓库不包含原企业内部数据、内部代码、个人身份信息或访问凭证。

## 发布步骤

1. 上传 `index.html` 和 `README.md` 到仓库 `main` 分支根目录。
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。
3. 等待部署完成，使用无痕窗口打开 Pages 地址，检查筛选、页面切换、注释及横向滚动。

## 注意

这是公开的静态演示作品集。所有浏览器端数据及 JavaScript 均可被访问者查看。
