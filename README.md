# MALL / INSIGHTS · 商业化增长数据分析作品集

首页为招聘展示导览，保留原有七个交互分析模块。

## 部署
将 `index.html` 和 `README.md` 上传至 GitHub 仓库根目录，并通过 GitHub Pages 的 `main / (root)` 发布。

## 数据说明
交互分析数据均为合成模拟数据，历史项目成果独立展示，不参与模拟指标计算。请勿将模拟经营数据视为企业真实数据。

## 分层展示（招聘展示版）
- 第一层：经营结果与业务决策
- 第二层：可展开的分析定义、参数、阈值和局限
- 第三层：`methods/` 目录下的独立 Python 模拟分析脚本

**重要口径区别**：交互看板使用合成访问事实表实时计算；Python 演示脚本是各方法的独立模拟练习，并非在线页面的计算后端。RFM/K-means 是离线快照，不能用来宣称按任意月份实时分层。V3.7 已统一 ABC 在线与离线临界 SKU 分类规则；但两者使用不同模拟样本，结果数值不要求一致。


## V3.7 方法验收与量化结果

- 五种分析方法的展开区新增**运行仓库内独立模拟 Python 脚本得到的离线结果快照**。它们与浏览器实时筛选看板采用不同模拟样本，不能互相视为同一结果。
- 在线商品 ABC 的临界 SKU 规则改为与离线一致：**加入当前 SKU 后的累计 GMV 占比** ≤70% A、≤90% B、其余 C。
- RFM 规则有八类，本次模拟数据仅出现七类；K-means K=5 为显式配置，诊断结果也予以展示。
- A/B 演示脚本不再把模拟统计显著性直接解释为真实业务全量上线。
- 五种方法仍提供原始脚本和适用边界；方法区数字为**离线脚本实算的模拟数据**，历史真实项目业绩仍独立展示。
